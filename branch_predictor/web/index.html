Branch predictor demos

The two demos are separate. In each one, use the Branches slider to add branches, then click T (taken) or NT (not taken) next to a branch to send it an outcome. Clicks wait in a queue of up to 5, and extra clicks are dropped. Changing the table size or history length resets that predictor.

Bimodal

The low bits of each branch's PC pick one of the table's 2-bit saturating counters. Every outcome moves that counter one step toward T or NT, and the counter predicts whichever half it's in. Shrink the table and branches start sharing counters (aliasing). The letters under each dial show which branches map to it.

GShare

The global history (the last few outcomes of every branch) is XORed with the branch's PC to pick a counter, so one branch uses a different counter for each recent pattern. A counter's dial appears the first time a branch maps to it, and the letters under each dial show which branches map to it right now.
